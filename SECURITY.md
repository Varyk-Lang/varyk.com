# Security

To report a vulnerability in this website or in the Varyk compiler, email
[security@varyk.com](mailto:security@varyk.com). Please do not open a public
issue, and please do not disclose the problem publicly until a fix is
available.

Include what you found, how to reproduce it, and which version or commit you
tested. The same information is published at
<https://varyk.com/.well-known/security.txt> and <https://varyk.com/security/>.
