# Move varyk.com to Zola

## Overview

Replace the hand-written `public/` placeholder with a Zola site modelled on rust-lang.org's structure: Home, Install, Learn (Getting started, Reference, Examples), Tools, Design (with Roadmap), Community, and Blog in the nav; Security and License in the footer. Same design as today, no syntax highlighting, no JavaScript. Every claim about Varyk traces to the compiler repository (spec, roadmap, examples, license files). The site and this repository are public and written for outside readers.

Launch order: compiler repo public, first release, then the site. Content is written for the post-release state; details only the release can settle are marked `TODO(release)` in HTML comments and listed in a README launch checklist. The site does not launch with a marker left.

Content is plain Markdown with no shortcodes, so a short post-build script can write a Markdown copy of each page and `/llms.txt` for AI agents. Zola is not in the Workers Builds image, so `scripts/build.sh` downloads a pinned, checksum-verified Zola for the current OS and runs `zola build` into `public/`. `wrangler.jsonc` keeps serving `./public`.

## Development Approach

- Zola v0.23.6. `highlight_code = false`; Zola still emits `class="language-varyk"` / `language-rust` on code blocks, so tag Varyk blocks ```varyk (never ```rust: the Markdown copies go to AI agents).
- No shortcodes in content. Side-by-side examples are two fenced blocks inside a `<div class="panes">`.
- One base template; partials for head, nav, and footer; `index.html`, `section.html`, `page.html`, `blog.html`, `blog-page.html`, `404.html` extend it. Nav, footer columns, and the repository URL live in `config.toml` `extra`.
- Per page: unique `<title>` (`Page · Varyk`), description, canonical, OG tags, from front matter. JSON-LD `WebSite` on every page and `BreadcrumbList` on nested pages (data only; the CSP allows it). Zola's built-in robots.txt (allow all) and sitemap.
- `scripts/agents.py` (standard library): for each content file, strip front matter and HTML comments, write `index.md` beside the page's `index.html`; write `/llms.txt` (title, summary, sections linking the `.md` copies). Refuses to run if any content file contains `{{` or `{%`. Head links the `.md` copy with `rel="alternate" type="text/markdown"`.
- Text about Varyk traces to the compiler repo; site-owned text (security, license, chrome) is short and makes no language claims.
- Verification by output: build, spec byte-comparison for the borrowing code, `wrangler dev` checks, Playwright at 360 and 1280 px, Lighthouse SEO and accessibility.
- Not needed: highlighting (turn on later with a `varyk` grammar), `llms-full.txt`, `noindex` handling or a custom sitemap, images (an `og:image` is a launch-checklist item), Rust toolchain, Node dependencies.
- Branch `zola`, one commit per task, merge to `main` at the end.
